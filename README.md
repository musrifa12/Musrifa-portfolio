# Mushrifa — Creative Modern Portfolio

Responsive five-page portfolio using plain HTML, CSS and JavaScript.

## Pages
- index.html — Home and introduction
- about.html — Profile, education and languages
- work.html — Projects and Robo Race workshop
- skills.html — Technical and professional skills
- contact.html — Email, phone, location and contact form

## Run
Extract the ZIP, open the folder in VS Code, right-click index.html and select Open with Live Server.

## Assets
- assets/mushrifa-photo.jpg — supplied photograph
- assets/mushrifa-resume.pdf — supplied resume

The contact form opens the visitor's default email application. It does not store messages. Content is based on the supplied one-page resume; no GitHub/LinkedIn links, CGPA or unspecified project details have been invented.
